Управление программами фонда, двумя вариантами вывода, шапками и независимым порядком карточек.

== Установка ==

1. В админке WordPress откройте «Плагины» → «Добавить новый» → «Загрузить плагин».
2. Выберите архив lv-programs.zip, установите и активируйте его.
3. Откройте новый раздел «Программы фонда».

== Использование ==

* [lv_programs_home] — блок для главной страницы.
* [lv_programs_page] — блок для отдельной страницы программ.

В разделе «Программы фонда» используется упрощённая форма: название, описание, рубрика, необязательная ссылка на страницу программы и фотография.

Если ссылка на страницу программы указана, под описанием карточки появляется ссылка «Подробнее о программе». Если поле оставить пустым, этот элемент не выводится.

На странице «Шапки блоков» редактируются три надписи каждого блока и их видимость.

На странице «Порядок и показ» карточки перетаскиваются отдельно для главной и страницы программ.

Там же переключателем «Показывать» можно отдельно включить или скрыть каждую программу в каждом из двух блоков.

== Важно ==

Плагин управляет только программами фонда. Блок «Направления работы» остаётся самостоятельной HTML-вставкой.
